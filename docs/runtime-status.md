# 运行状态

管理员登录控制台后，打开侧栏的「运行状态」。经典前端与 Next 前端均提供此页面，普通用户和游客无法读取监控接口。

## 查看哪些信息

- **服务节点**：节点名称、版本、启动时间、在线状态，以及进程 CPU 和内存趋势。点击节点卡片查看详情，每页展示 6 个节点。
- **数据库**：当前进程实际连接的 SQLite、PostgreSQL 或 MySQL，以及连接探测状态和耗时。
- **Redis**：是否配置、能否读写节点注册信息，以及操作耗时。不会返回连接地址、用户名或密码。
- **AI 上下文缓存**：最近 24 小时的输入令牌、缓存读取和写入令牌、有缓存用量的请求数，以及上游确认与估算用量的请求数。

CPU 按进程使用的核数显示，例如 `0.5 核`。内存区分进程常驻内存、主机已用内存和容器内存限制。完整资源采集适用于 Linux；其他平台或无法读取的资源显示为 `—`，不会按零处理。

## 多节点部署

所有节点连接相同的 Redis 逻辑数据库后，会自动汇总到同一页面。节点名称来自 `HOSTNAME` 或 `COMPUTERNAME`，没有可用名称时生成临时名称；每次进程启动另有独立实例标识。不同部署环境应使用不同 Redis 逻辑库或实例。

节点每 10 秒更新一次心跳。超过 30 秒未更新标记为数据过期，超过 5 分钟从注册表移除。Redis 连接失败时保留最后观测到的节点并标记状态未知，不把它们认定为在线。注册表最多保留 256 个实例，达到上限时页面给出提示。

未配置 Redis 时，页面仅展示本次请求命中的节点。负载均衡可能把下一次请求分配到另一节点，因此多节点部署应配置共享 Redis。

## 采样与统计口径

资源每 10 秒采样，最多保存 60 个点，保存在进程内存中。节点重启后趋势清空，这个页面不提供长期历史或告警。页面隐藏时暂停轮询。

数据库与 Redis 探测在后台执行，页面接口只读取已有快照。缓存用量每分钟更新一次，通过 Redis 短租约协调共享查询；未配置 Redis 时由本节点查询。查询限定最近 24 小时，并设置 2 秒截止时间。查询失败或数据过期会保留旧值，同时显示异常状态和采样时间。

缓存令牌仅汇总公共调用账本中上游确认的用量。输入令牌按协议语义统一为包含缓存的总量；估算用量单独计数。提供商未返回缓存字段，不代表没有命中缓存，因此页面不据此计算命中率。

此处不统计 Redis 存储占用、提供商内部 KV 缓存容量，也不包含企业扩展独立维护的服务账号用量账本。需要长期趋势、基础设施全量监控或告警时，配合专门的监控系统使用。
