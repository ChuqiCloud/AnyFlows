# 系统 API Token

系统 API Token（PAT）用于脚本调用系统 API。模型调用继续使用模型 Key，两者具有独立的权限、存储和生命周期。

## 创建与使用

1. 登录控制台，在凭据管理入口切换到「系统 API Token」。
2. 填写用途名称，选择权限预设或自定义权限，设置有效期和可选的 IP/CIDR 白名单。
3. 创建时需要最近 5 分钟内的交互登录。页面提示重新登录时，可使用站点已启用的密码、Passkey 或 OAuth，返回后继续填写。
4. 保存完整令牌。明文仅在创建成功时显示一次，关闭后无法恢复。

例如，具备 `billing:read` 权限的令牌可查询本人的钱包：

```bash
curl "$ANYFLOWS_BASE_URL/api/account/wallet" \
  -H "Authorization: Bearer $ANYFLOWS_ACCESS_TOKEN"
```

使用 `GET /api/access-token/self` 查看当前令牌的 ID、权限和到期时间。令牌只通过 Bearer 请求头传输，不放进 URL、查询参数或额外用户 ID 头。

## 权限与模型 Key

普通用户令牌只允许访问本人有权使用的资源。管理员令牌可选择全部已登记业务及后台接口，也可按具体操作收窄。全权限在创建时展开为明确权限集合；之后新增接口不会自动加入旧令牌。每次请求仍检查用户当前角色、账号状态和原有业务规则。

常用权限包括：

| 权限 | 用途 |
| --- | --- |
| `account:read` | 读取本人资料 |
| `models:read` | 读取系统模型目录 |
| `usage:read` | 读取本人用量和审计 |
| `billing:read` | 读取本人钱包和账单 |
| `api_keys:read` / `api_keys:write` | 查询或管理本人模型 Key |
| `routes:read` / `routes:write` | 查询或管理本人路由 |
| `merchant:read` / `merchant:write` | 查询或管理本人商户服务 |
| `merchant_secrets:write` | 录入或替换上游凭据，同时需要商户写权限 |
| `admin:<操作标识>:execute` | 执行指定后台操作，仍需当前管理员权限 |

完整权限以创建页面返回的目录为准。模型 Key 管理权限允许创建独立的模型 Key：新 Key 由自身的有效期、额度、模型和 IP 范围约束，PAT 过期或撤销不会停用它。需要停用模型 Key 时，应单独操作该 Key。

PAT 不能签发、修改、恢复或撤销 PAT，也不能管理登录会话。这些凭据控制操作始终要求浏览器交互会话。扩权、放宽 IP 范围、延期和重新启用还需要短时、单次且绑定本次参数的验证证明。

## 轮换与应急处置

轮换时先创建新令牌，在脚本中替换并确认后，再撤销旧令牌。列表只展示识别片段和最近使用时间、IP；不要通过截图或日志传递完整令牌。

用户可撤销自己的全部 PAT。管理员可撤销指定用户全部 PAT，或关闭全局 PAT 认证、暂停新令牌签发。策略以数据库为准，后续请求立即重新检查。全局关闭不影响交互会话和模型 Key；重新打开不会恢复已撤销令牌。

撤销不追溯回滚已开始执行的请求。已受理的异步资金任务保留来源信息；首次对外提交前复核操作者当前权限。通过复核后会原子记录首次发送授权；已授权发送或结果未知的任务继续查询对账，避免重复付款或错误释放预留资金。

## 错误与运行配置

| 状态 | 含义 |
| --- | --- |
| 400 | 请求或凭据传递方式不合法 |
| 401 `invalid_token` | 令牌无效、过期、停用或已撤销 |
| 403 `insufficient_scope` | 缺少接口所需权限 |
| 403 `interactive_session_required` | 该操作只能使用交互会话 |
| 403 `recent_authentication_required` | 重新交互登录后继续敏感令牌操作 |
| 409 | 版本冲突或达到数量上限，刷新列表后处理 |
| 429 | 请求过快，按 `Retry-After` 重试 |
| 503 | PAT 已全局关闭或认证存储暂不可用 |

默认每用户最多 20 枚未撤销令牌，可由管理员调整。请求使用数据库共享限流：每来源 IP 每分钟 600 次认证尝试，每枚 PAT 每分钟 120 次、每用户每分钟 300 次；固定窗口边界允许短时突发。验证证明按用户限制为每 5 分钟 20 次。

IP 白名单使用现有的 [客户端地址配置](configuration.md#代理与客户端地址)。反向代理和应用日志应屏蔽 Authorization、Cookie 和含密钥正文。PAT 元信息与秘密响应均禁止缓存；访问审计默认保留 90 天并分批清理。
