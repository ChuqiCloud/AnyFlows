# 账号认证与企业空间

AnyFlows 将账号认证、企业空间开通和企业功能授权分别管理。账号认证用于确认个人或企业主体；企业空间开通用于创建工作空间；功能授权决定空间可使用的能力、容量和有效期。

## 个人与企业认证

登录后进入个人工作台的「账号认证」，选择个人认证或企业认证，填写主体名称、认证说明并上传证明材料。

- 支持 PDF、PNG、JPEG 和 WebP，每次 1–5 份材料，单份不超过 10 MB，总计不超过 25 MB。
- 提交前可预览所选文件；提交后在认证记录中展开详情，再按需预览或下载材料。
- 平台管理员在「企业认证」的「账号认证审核」页处理申请，可以通过、要求补充或驳回。要求补充和驳回必须填写理由。
- 申请人可以查看自己的申请、审核结果、理由和材料。审核通过后，材料继续保留。
- 补充或驳回后重新提交会生成新记录，原申请及其审核结果保留。同类型认证待审核或已通过时，不接受重复提交。

认证记录按提交时间倒序展示，每页 25 条，支持状态筛选和继续加载。列表只读取记录摘要；材料正文在用户点击预览或下载时才请求。PDF 无法在浏览器内预览时，可以下载后查看。

个人认证通过不会授予企业空间资格。企业认证通过后，账号自动获得企业申请入口，可以申请开通企业空间；这不会将账号提升为平台管理员，也不会授予其他企业的访问权限。

## 支付宝个人认证配置

支付宝 CertDoc 认证需要站点地址和支付宝应用配置同时就绪：

1. 在 AnyFlows 后台「站点设置」填写对外可访问的公开地址，例如 `https://example.com`。该地址用于生成授权回调；留空时提交会失败，尚未请求支付宝。
2. 在支付宝开放平台为同一个应用配置网页授权回调地址（控制台只要求域名时填写对应域名）。完整回调路径为 `https://example.com/api/account/verifications/alipay/callback`。回调必须可从浏览器访问，且不能被 CDN 登录页或验证码拦截。
3. 在「实名认证配置」启用支付宝认证，填写该应用的 App ID、应用私钥和支付宝公钥，并确认应用具备 CertDoc 接口及 `id_verify` 授权能力。

用户提交姓名和身份证号后，服务端先执行 `alipay.user.certdoc.certverify.preconsult`，再返回支付宝授权入口。用户完成授权后，回调接收 `auth_code` 与 `state`，换取访问令牌并执行 `alipay.user.certdoc.certverify.consult`，最后保存认证结果。

电脑端显示二维码，用户使用本人支付宝扫码授权。手机端会尝试唤起支付宝；浏览器拦截唤起时，可点击「打开支付宝」重试，或在支付宝「扫一扫」中识别二维码截图。在支付宝内打开认证页时，直接访问授权页，无需再次唤起 App。二维码在浏览器本地生成，不发送到第三方服务。

AnyFlows 的认证窗口为提交成功后 10 分钟。这是本站的授权有效期，不代表支付宝令牌的有效期。接口返回 `provider_expires_at` 和 `server_time`（Unix 秒），前端按服务端时间倒计时；过期或认证完成后不再展示授权链接。过期回调和已结束流程的重复回调不会修改认证结果。过期申请允许重新提交，新申请会生成新的 state；系统不保存完整证件号，重新发起时需再次填写。历史人工待审核或已通过的同类申请仍会阻止重复提交。

认证详情打开时，前端每 3 秒查询一次本站认证结果；页面进入后台、授权到期或认证结束后停止轮询。返回页面或点击「查看认证结果」可再次获取状态，不会重复请求支付宝核验接口。

站点备用域名不会自动替换公开地址或支付宝登记的回调域名。切换回调入口时，应同步更新两处配置。回调不依赖浏览器登录会话，授权码、令牌和完整证件信息不应写入日志。

提交阶段提示认证服务不可用时，先检查公开地址是否为空，再查看服务日志中的阶段、网关方法、HTTP 状态及错误码。授权后失败则检查回调地址登记、`auth_code`、应用权限和支付宝公钥；不要通过关闭验签来绕过问题。

## 企业空间开通

已完成企业认证的账号在「申请开通企业」中填写企业名称、标识、业务用途和开通材料。平台管理员单独审批空间申请，并设置初始授权。批准后，申请人成为该空间的 Owner，再进入初始化页面完成配置。

开通页保留本人申请历史，包括待审核、批准和拒绝的记录。展开历史记录可以读取原申请说明、审核理由及材料；已批准的申请提供初始化入口。已存在的申请可以继续查看和恢复，不会因为升级后的认证门槛而丢失。

升级前已通过企业空间资质认证的申请人兼容保留企业认证资格。原空间的认证记录和材料仍在「企业空间认证记录」中查看；有企业资料管理权限的成员可以访问本企业材料，平台管理员可以审核及查看。

旧企业认证在本次升级后保存每次审核和补交前的版本快照。升级前已经被覆盖的数据不能还原；旧记录未保存文件正文时会显示「历史材料正文不可用」，不会生成替代材料。

## 调整企业授权

平台管理员在企业目录选择「管理授权」，可以在空间开通后继续调整：

| 设置 | 用途 |
| --- | --- |
| 团队管理 | 开启或关闭团队管理能力 |
| SSO | 开启或关闭企业 SSO 及其域名管理能力 |
| 自定义角色 | 开启或关闭自定义角色能力 |
| 席位、团队和企业 Key 上限 | 调整企业容量；不能低于当前占用 |
| 审计保留天数 | 设置 1–3650 天的授权保留期 |
| 生效时间、到期时间和宽限期 | 调整授权时间范围 |

修改必须填写理由并提交当前授权版本。多人同时编辑时，旧版本请求会被拒绝；刷新后确认最新设置再提交。平台管理员无需加入该企业，也不需要代替 Owner 登录。

关闭 SSO 时，系统同时解除该企业的强制 SSO 登录策略，保留已有身份提供商、域名和绑定配置。重新开启 SSO 不会自动恢复强制登录；企业管理员应检查配置和恢复入口后再设置强制策略。SSO 和域名当前使用同一个授权开关。

授权变更与平台审计记录在同一数据库事务中提交。审核认证不会自动增加席位、额度或开启 SSO；这些设置以企业授权为准。

## 材料访问边界

认证和开通材料使用管理会话鉴权，不提供公开文件地址。本人只能读取自己的账号认证和开通申请；企业材料按所属企业与权限校验。平台管理员读取账号认证记录及材料会记录平台审计，审核人不能审核自己的账号认证。

文件响应禁用缓存。前端仅在页面内存中保留预览对象，关闭预览或离开组件时释放，不写入浏览器持久化存储。普通 API 列表不会返回文件正文。
