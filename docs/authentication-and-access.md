# 账号与 API Key

后台登录会话用于管理自己的账号和系统；API Key 用于调用模型。两者不能混用。

## 登录和个人资料

管理员完成首次初始化后，用户可按站点开放的方式登录。密码、Passkey 和 OAuth 是否可用，由管理员配置。登录过期后重新登录，不要在模型客户端中填写后台登录令牌。

公开注册是否需要邮箱验证取决于站点的邮箱要求；用户可在个人资料中绑定、激活或更换邮箱。Passkey 需要浏览器支持的安全上下文，正式站点使用 HTTPS。登录域名及相关启动配置变更后，应检查 Passkey 配置并按要求重启服务。

## 创建和使用 API Key

在控制台的 API Key 页面创建密钥，设置名称、额度、有效期、模型范围和 IP 限制。完整密钥只在创建成功时显示一次，列表中的前缀不能用来调用模型。丢失后创建新密钥，验证后停用旧密钥。

调用示例，将域名、密钥和模型名替换为实际值：

```bash
curl https://api.example.com/v1/chat/completions \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"YOUR_MODEL","messages":[{"role":"user","content":"你好"}]}'
```

不要将密钥放在 URL、截图、公共 issue 或前端静态资源中。长期使用时通过客户端的密钥配置或环境变量管理。

用户通过 `/api/tokens` 管理自己的密钥。管理员通过 `/api/admin/tokens` 代用户管理网关 API Key，可以指定用户、分组和相应策略；这些密钥仍然用于调用模型，不会因此获得后台管理员权限。管理员身份由登录账号和管理会话决定。

## 注册与邀请奖励

管理员在「注册与邀请奖励」配置默认分组和以下额度：

| 设置 | 发放条件 |
| --- | --- |
| 新用户注册赠送 | 公开注册成功 |
| 邀请人奖励 | 新用户使用有效邀请码注册成功 |
| 受邀用户额外奖励 | 同上，额外发放给新用户 |

设置为 0 时不发放该项奖励。受邀用户的开户余额为注册赠送与受邀额外奖励之和。修改规则不补发历史奖励；管理员开户和企业 SSO 开户不参加公开注册奖励。

用户在「邀请中心」查看邀请码、邀请记录和当前规则。关闭公开注册后，邀请链接不能创建新账号。

## 认证与扩展功能

个人及企业主体认证见 [账号认证](account-and-enterprise-verification.md)。企业空间、企业 SSO 和 SCIM 由企业扩展提供，社区版不包含对应管理页面；企业主体认证通过也不会赋予平台管理员权限。

企业发行版中的企业 API Key、服务账号凭据和 SCIM 令牌各有用途，应按对应功能配置。不能用 SCIM 令牌调用模型，也不能用模型 API Key 登录后台。

## 调用失败时检查什么

| 情况 | 先检查 |
| --- | --- |
| 401 | 凭据类型、密钥是否完整、状态和有效期 |
| 403 | 用户和分组权限、模型范围、IP 白名单 |
| 429 | 请求频率、并发数和上游限制 |
| 余额或额度不足 | 账号余额、Key 额度及模型价格 |
| 服务不可用 | 渠道状态、数据库、Redis 和运行日志 |

保留 HTTP 状态码、请求 ID 和脱敏错误内容，便于查询调用记录。在线查看接口和调试请求见 [API 目录](api-explorer.md)。
