# 账号与访问

登录会话用于账号和系统管理，API Key 用于模型调用，两类凭据分别使用。

## 登录和个人资料

管理员完成首次初始化后，用户可按站点开放的方式登录。密码、Passkey 和 OAuth 由管理员配置。会话过期后需重新登录。

注册时是否验证邮箱由站点配置决定，用户可在个人资料中绑定、激活或更换邮箱。Passkey 要求浏览器处于安全上下文，正式站点应使用 HTTPS。变更登录域名后，检查 Passkey 配置；修改启动配置后需重启服务。

## 创建和使用 API Key

在控制台的「API Key」页面创建密钥，设置名称、额度、有效期、模型范围和 IP 限制。完整密钥仅在创建时显示一次，列表只显示前缀。密钥丢失后需重新创建，并停用旧密钥。

创建时可选择管理员开放的分组。选择「跟随默认分组」后，Key 随账号默认组调整；明确选择某个组后，该 Key 固定使用所选组。不同 Key 可以绑定不同分组，分组同时决定可路由的模型、渠道和计费倍率。选择器显示基础倍率，实际费用还受模型价格、来源组附加倍率和高峰倍率影响。

Key 创建后，用户编辑名称、额度或限制不会改变其分组。需要换组时创建新的 Key，再停用旧 Key；管理员仍可通过令牌管理修改绑定。

调用示例，将域名、密钥和模型名替换为实际值：

```bash
curl https://api.example.com/v1/chat/completions \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"YOUR_MODEL","messages":[{"role":"user","content":"你好"}]}'
```

通过客户端的密钥配置或环境变量保存密钥，避免写入 URL、截图、公共 issue 或前端静态资源。

用户通过 `/api/tokens` 管理自己的密钥。管理员通过 `/api/admin/tokens` 代用户管理 API Key，可指定用户、分组和调用策略。管理员代建的密钥仅用于模型调用，后台权限取决于登录账号。

## 开放分组供用户选择

管理员在分组管理中为已有分组单独保存「Key 自助选组策略」：

| 策略 | 创建 Key 时可选择该组的用户 |
| --- | --- |
| 仅默认组用户 | 账号默认组为该组的用户 |
| 全部用户可选 | 所有有效登录用户 |
| 指定用户可选 | 获得授权的用户，以及默认组为该组的用户 |

新组及升级前的分组默认采用「仅默认组用户」。此策略独立于独占分组、模型展示和渠道配置；开放选组后仍需给该组配置可用渠道与模型。

策略变更默认只影响之后创建 Key 的可选范围。保存时可勾选停用失去授权的现有 Key，并在确认后同时保存策略与停用结果；默认组用户仍保留使用权限。保存后会显示停用的 Key 数和受影响的用户数。已停用且不再获准使用该组的 Key，用户不能自行重新启用。

创建请求提交时会再次校验当前策略；页面打开后授权发生变化，用户需刷新可选分组后重试。

计费附加倍率按账号默认组与最终路由目标组匹配；Key 固定选组不会改变账号默认组。升级时若已有固定分组 Key，并配置了来源组到目标组的附加倍率，请核对该组合的计价设置。

## 分组模型范围与模型分时倍率

管理员可在分组管理的「模型范围」中设置该组允许调用的模型。留空表示不额外限制；设置白名单后，实际可用模型为分组范围与 Key 自身模型范围的交集，同时仍需有可用渠道。用户模型目录、供应商筛选和 API 模型列表按同一范围过滤。

模型价格配置支持独立的可选分时倍率，包括每周日期、多个时段、固定 UTC 偏移、跨午夜、加价和折扣。模型规则在当前时段命中时，优先替换分组的时段倍率；未命中或未配置模型规则时，沿用分组的时段规则。模型与分组的时段倍率不会相乘，分组基础倍率和来源组附加倍率仍按原规则计入。

例如，分组晚间倍率为 1.5，某个模型同一时段设置为 0.8，则该模型使用 0.8 的时段倍率；其他模型仍使用 1.5。规则结束后，该模型恢复继承分组。异步视频任务按提交时生效的倍率冻结，后续计费不会因规则变化重新取值。

## 注册与邀请奖励

管理员在「注册与邀请奖励」配置默认分组和以下额度：

| 设置 | 发放条件 |
| --- | --- |
| 新用户注册赠送 | 公开注册成功 |
| 邀请人奖励 | 新用户使用有效邀请码注册成功 |
| 受邀用户额外奖励 | 同上，额外发放给新用户 |

额度为 0 时不发放对应奖励。受邀用户的初始余额为注册赠送与受邀额外奖励之和。修改规则不补发历史奖励；管理员创建的账号不参加公开注册奖励。

用户在「邀请中心」查看邀请码、邀请记录和当前规则。关闭公开注册后，邀请链接不能创建新账号。

## 个人与企业主体认证

社区版支持个人和企业主体认证。登录后打开「账号认证」，按页面提供的方式申请。管理员在「实名认证配置」中设置可用方式和说明要求。

人工审核需填写主体名称、证件签发国家或地区、证件类型和号码，并上传材料。支持 PDF、PNG、JPEG、WebP，每次 1–5 份，单份不超过 10 MB，总计不超过 25 MB。提交后可查看记录、材料和审核结果；要求补充或驳回后按理由重新提交。

同一时间只能有一份待处理申请。认证通过后显示脱敏主体信息；变更主体时可申请更换，审核期间保留原认证资格。

管理员在「账号认证审核」中按状态和主体类型筛选记录，查看材料后选择通过、要求补充或驳回。后两项必须填写理由，审核人不能审核自己的申请。材料不提供公开地址，申请人可查看自己的材料，管理员按权限读取并记录审计。

### 支付宝个人认证

管理员启用支付宝方式前，需完成以下配置：

1. 站点设置中填写可访问的 HTTPS 公开地址，如 `https://example.com`。
2. 在支付宝开放平台登记同一应用的回调地址：`https://example.com/api/account/verifications/alipay/callback`；仅要求域名时填写对应域名。
3. 填写 App ID、应用私钥和支付宝公钥，确认应用具备 CertDoc 接口及 `id_verify` 授权能力。应用私钥和支付宝公钥分别填写，保存后不回显；更新时留空保留原值。启动配置见 [配置参考](configuration.md)。

用户使用本人支付宝扫码或从手机打开支付宝完成授权，有效期为提交成功后 10 分钟，过期后重新发起。提交失败时检查站点地址、应用配置和服务端错误码；授权后失败时检查回调、应用权限和验签。更换域名需同步更新站点及支付宝配置。

主体认证用于核验账号主体信息，不授予管理员权限。

## API 目录与在线调试

打开站点 `/api` 页面，可搜索接口、查看参数并发送调试请求。目录按当前身份过滤：

| 身份 | 可见接口 |
| --- | --- |
| 游客 | 公开接口和模型网关接口 |
| 登录用户 | 公开接口和本人可用的管理接口 |
| 管理员 | 完整管理目录 |

实际请求仍需通过认证、权限和额度检查。页面仅允许执行调试白名单中的 GET 接口和模型网关 POST 接口；管理写入、OAuth、Webhook、初始化等接口仅供查阅。

管理读取请求使用当前登录会话，模型请求需单独填写 API Key。Key 不写入 URL 或浏览器持久化存储，刷新后需重新输入。响应区显示状态码、耗时、请求 ID 和截断后的正文；流式响应及长时间任务使用对应客户端验证。

目录接口为 `GET /api/explorer/catalog`，支持 `q` 搜索、`tag` 筛选、`page` 和 `page_size` 分页。页码从 1 开始，最大 10000；每页 1–100 条，默认 24。`GET /api/explorer/catalog/{operation_id}` 返回单项接口定义，无权限和不存在的操作返回相同错误。目录和详情不缓存。

## 调用错误排查

| 情况 | 检查项 |
| --- | --- |
| 401 | 凭据类型、密钥是否完整、状态和有效期 |
| 403 | 用户和分组权限、模型范围、IP 白名单 |
| 429 | 请求频率、并发数和上游限制 |
| 余额或额度不足 | 账号余额、Key 额度及模型价格 |
| 服务不可用 | 渠道状态、数据库、Redis 和运行日志 |

排查时记录 HTTP 状态码、请求 ID 和脱敏错误内容，以便关联调用记录。上游配置与请求头诊断见 [渠道管理](channels.md)。
