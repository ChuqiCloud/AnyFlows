# 代理池

管理员在“专属代理”页管理代理池。每个池拥有固定 ID，可在凭据编辑器中像单个代理一样选择。池内节点也有独立 ID，支持手动绑定。

## 导入和订阅

支持粘贴文本、上传 TXT/CSV/JSON 文件，以及 GET URL 订阅。每次导入最多 1 MiB、256 个去重节点；填写导入内容会替换当前成员。支持以下格式：

```text
http://user:password@192.0.2.1:3129
https://192.0.2.2:8443
socks5://192.0.2.3:1080 #hk
socks5h://[2001:db8::1]:1080 #备注
192.0.2.4:1080
192.0.2.5:1080:user:password
```

裸地址使用编辑器指定的默认协议。认证信息包含 `@`、`#` 等保留字符时，应使用 URI 百分号编码。CSV 列顺序为 `host,port[,username,password[,scheme[,remark]]]`，支持引号包裹字段。JSON 支持 URI 字符串数组，以及包含 `host`/`ip`、`port`、`scheme`/`protocol`、`username`、`password`、`remark`/`name` 的对象数组，也支持 `proxies`、`data`、`list` 包装。

导入时会提取混合文本中的明确代理地址、保留备注、规范化去重，并返回无效项和重复项数量。同一行可包含多个代理 URI，支持中文说明和含空格的行尾备注；以 `#`、`;`、`//` 开头的整行注释会跳过。不支持的条目不会进入选路。订阅抓取失败、空列表或超限列表不会清空上次成员。订阅中移出的节点不再参与该池选路，已有单节点手动绑定仍保留。

## 测活和选路

保存后后台扫描会按配置间隔更新订阅并检测节点，也可以手动执行“测活”或“更新并测活”。每个池可单独设置间隔，支持秒、分钟、小时，范围为 1 分钟至 24 小时，默认 15 分钟；切换单位会保留实际时长。后台约每 15 秒扫描一次，到期任务在扫描时执行。

页面显示最近检测时间、同步成功时间、同步尝试时间和预计下次同步时间。订阅更新失败会保留原成员，按设定间隔重试；手动测活只检测现有节点，不推迟订阅同步。修改配置后会重新安排维护任务，预计时间受正在运行的任务和后台扫描时间影响。

测活通过节点代理发送不带上游认证信息的 HTTPS GET 请求，保留证书验证，要求 2xx 响应和有界响应体。可设置实际业务站点的公开检测地址，例如 `https://opencode.ai/cdn-cgi/trace`。一次连接检测上限 5 秒，最多并行 32 个节点。

池仅选择启用、通过检测且检测结果未过期的节点，按凭据 ID 保持稳定选择；成员或健康集合变化后可能切换节点。健康有效期为配置间隔的两倍。HTTPS 可达并不代表特定模型或账号可用，也不代表公共代理长期稳定。请求失败不会在中途自动重放，节点淘汰和切换依据下一次健康检测。

绑定优先级：

1. 凭据明确绑定的单节点或代理池。
2. 当前渠道绑定的代理池。
3. 全局绑定的代理池。
4. 原有网络设置中的默认出口。

明确绑定的池没有健康节点时，请求失败关闭，不会向下回退。渠道测试连接、模型发现和生产转发使用同样的选择规则。后台订阅抓取继承原有受控网络设置，避免通过正在更新的动态池产生循环依赖。

运行时使用短期缓存，其他实例的绑定和健康变动最多在约 5 秒后可见。配置更新使用版本校验，跨实例维护任务使用数据库租约；旧检测结果不能覆盖新配置。

## 密钥与管理

订阅地址可能包含查询 token，保存时加密，管理响应只返回来源主机名；编辑时留空保留原地址。节点密码复用专属代理密码加密和记录身份隔离。错误响应和日志不包含原始订阅 URL、代理密码或导入内容。

删除仍被凭据、渠道或全局引用的池会被拒绝，需先解除绑定。删除池会保留节点目录，避免破坏单节点绑定。手动修改节点会撤销此前的健康结论，需重新检测。

## 批量删除与清理

代理池和节点列表支持勾选当前列表后批量删除。池内可以直接清理“未通过”节点，专属代理目录可以清理未被凭据或当前池成员使用的节点，无须先勾选。待检测、配置变更后需要重测的节点不会计入检测失败。

操作先预览可删除、受保护和跳过的项目 ID，确认后执行；执行时会重新检查引用和配置版本。选择或版本变化后需重新预览。仍被凭据、渠道或全局引用的池、正在执行维护的池，以及被凭据或其他池使用的节点均会保留，不会自动解除绑定。删除池会保留节点目录；清理池内节点会同步移出当前成员。

每批最多处理 256 项，存在后续项目时可点击“预览下一批”继续，受保护项目不会阻塞后续批次。清理仅作用于确认的项目；订阅内容未变化时，下次同步可能重新导入被清理的节点。
