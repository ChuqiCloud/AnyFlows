# 代理池

管理员在「专属代理」页面管理代理池，并在凭据编辑器中绑定。代理池和节点各有独立 ID，也可直接绑定单个节点。

## 导入和订阅

支持粘贴文本、上传 TXT/CSV/JSON 文件，或填写通过 GET 获取的订阅地址。每次导入最多 1 MiB、256 个去重节点，导入内容会替换当前成员。支持以下格式：

```text
http://user:password@192.0.2.1:3129
https://192.0.2.2:8443
socks5://192.0.2.3:1080 #hk
socks5h://[2001:db8::1]:1080 #备注
192.0.2.4:1080
192.0.2.5:1080:user:password
```

裸地址使用编辑器指定的默认协议。认证信息包含 `@`、`#` 等保留字符时，应使用 URI 百分号编码。CSV 列顺序为 `host,port[,username,password[,scheme[,remark]]]`，支持引号包裹字段。JSON 支持 URI 字符串数组，以及包含 `host`/`ip`、`port`、`scheme`/`protocol`、`username`、`password`、`remark`/`name` 的对象数组，也支持 `proxies`、`data`、`list` 包装。

导入时会提取代理地址、保留备注并去重，显示无效项和重复项数量。同一行支持多个代理 URI、中文说明和含空格的行尾备注；以 `#`、`;`、`//` 开头的整行按注释忽略。

订阅获取失败、返回空列表或超限列表时保留原成员。订阅移出的节点不再参与该池选路，但已有单节点绑定仍保留。

## 测活和选路

保存后，后台按配置间隔更新订阅并检测节点，也可手动执行「测活」或「更新并测活」。每个池可单独设置间隔，范围为 1 分钟至 24 小时，默认 15 分钟。后台每 15 秒扫描一次，到期任务在扫描时执行。

页面显示最近检测、同步成功、同步尝试和预计下次同步时间。订阅失败后按设定间隔重试；手动测活只检测现有节点，不推迟订阅同步。配置变更后重新安排维护任务，实际执行时间可能受当前任务和扫描间隔影响。

测活通过代理发送不带上游凭据的 HTTPS GET 请求，并校验证书。检测要求返回 2xx，响应体不超过 64 KiB。可使用业务站点的公开检测地址，例如 `https://opencode.ai/cdn-cgi/trace`。单次检测限时 5 秒，最多并行 32 个节点。

池仅选择已启用、检测通过且结果未过期的节点，并按凭据 ID 稳定分配；成员或健康状态变化后可能切换。检测结果有效期为配置间隔的两倍。测活验证 HTTPS 可达性，模型和账号权限需单独验证。请求失败后不会经其他节点自动重放，后续节点选择以健康检测结果为准。

绑定优先级：

1. 凭据明确绑定的单节点或代理池。
2. 当前渠道绑定的代理池。
3. 全局绑定的代理池。
4. 原有网络设置中的默认出口。

绑定的池没有健康节点时返回错误，不再尝试低优先级出口。渠道测试、模型发现和生产请求使用相同规则。订阅获取使用系统网络设置，不经过正在更新的动态池。

绑定和健康状态使用约 5 秒的缓存，多节点更新可能存在延迟。配置更新会检查版本，跨实例维护任务通过数据库租约协调。

## 凭据与删除

订阅地址和节点密码加密保存。管理接口仅返回订阅来源主机名，编辑时留空保留原地址。错误响应和日志不输出原始订阅地址、代理密码或导入内容。

删除代理池前需解除凭据、渠道和全局绑定。删除池会保留节点目录及单节点绑定。手动修改节点后需重新测活。

## 批量删除与清理

代理池和节点列表支持批量删除。池内可清理「未通过」节点，专属代理目录可清理未被凭据或代理池使用的节点。待检测或因配置变更而待重测的节点不计入检测失败。

操作前需预览可删除、受保护和跳过的项目，确认后执行。执行时重新检查引用和配置版本；选择或版本变化后需重新预览。仍被引用或正在维护的池、被凭据或其他池使用的节点会保留。清理池内节点时同步移出当前成员。

每批最多 256 项，可通过「预览下一批」继续处理。清理仅删除已确认的项目；订阅仍包含这些节点时，下次同步可能重新导入。
