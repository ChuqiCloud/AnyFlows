# API 目录与在线调试

打开站点的 `/api` 页面，可搜索接口、查看参数并发送调试请求。业务集成使用对应客户端或 SDK。

## 可见范围

| 身份 | 可见接口 |
| --- | --- |
| 游客 | 公开接口、模型网关接口 |
| 登录用户 | 公开接口及个人可用的管理接口；已安装扩展按权限补充 |
| 管理员 | 完整管理目录及已安装扩展的接口 |

目录按当前身份过滤，实际请求仍需通过接口认证、权限和额度检查。

## 调试请求

选择接口后填写参数或请求体。页面仅允许执行列入调试白名单的 GET 接口和模型网关 POST 接口；管理写入、OAuth、SSO、Webhook、初始化等接口仅供查阅。

后台读取请求使用当前登录会话；模型请求需要另外填写 API Key。Key 只用于当前页面请求，不写入 URL 或浏览器持久化存储，刷新页面后需重新输入。

响应区显示状态码、耗时、请求 ID 和截断后的正文。流式响应和长时间任务建议使用对应客户端验证。

## 目录接口

`GET /api/explorer/catalog` 返回接口摘要、标签和分页信息：

| 参数 | 说明 |
| --- | --- |
| `q` | 按操作 ID、路径、摘要及描述搜索，不区分大小写 |
| `tag` | 按标签筛选 |
| `page` | 从 1 开始，最大 10000 |
| `page_size` | 1–100，默认 24 |

响应包含 `operations`、`tags`、`total`、`page`、`page_size`、`has_more` 和 `viewer`。`GET /api/explorer/catalog/{operation_id}` 返回单项接口定义；无权限和不存在的操作返回相同的错误，避免暴露目录信息。

目录及详情不缓存。凭据使用说明见 [账号与 API Key](authentication-and-access.md)。
