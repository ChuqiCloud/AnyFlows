# API 目录与在线调试

站点的 `/api` 页面用于查找接口、查看参数和发起调试请求。正式业务调用使用客户端或 SDK。

## 可见范围

| 身份 | 可见接口 |
| --- | --- |
| 游客 | 公开接口、模型网关接口 |
| 登录用户 | 公开接口及个人可用的管理接口；已安装扩展按权限补充 |
| 管理员 | 完整管理目录及已安装扩展的接口 |

目录在服务端按权限过滤。能看到接口说明不代表无需认证，也不代表当前 API Key 有额度或模型权限。

## 调试请求

选择接口后填写参数或请求体。通过调试白名单的 GET 接口和模型网关 POST 接口可直接执行；管理写入、OAuth、SSO、Webhook、初始化等流程只展示文档。

后台读取请求使用当前登录会话；模型请求需要另外填写 API Key。Key 只用于当前页面请求，不写入 URL 或浏览器持久化存储，刷新页面后需重新输入。

响应区显示状态码、耗时、请求 ID 和截断后的正文。调试器适合小范围验证；流式显示和长时间任务请使用对应客户端。

## 目录接口

`GET /api/explorer/catalog` 返回接口摘要、标签和分页信息：

| 参数 | 说明 |
| --- | --- |
| `q` | 按操作 ID、路径、摘要及描述搜索，不区分大小写 |
| `tag` | 按标签筛选 |
| `page` | 从 1 开始，最大 10000 |
| `page_size` | 1–100，默认 24 |

响应包含 `operations`、`tags`、`total`、`page`、`page_size`、`has_more`、`viewer`。`GET /api/explorer/catalog/{operation_id}` 返回当前身份可见的单项契约；无权限与不存在的操作不通过差异暴露目录。

目录及详情禁用缓存。接入客户端时仍需按目标接口执行认证、权限和额度校验。凭据使用说明见 [账号与 API Key](authentication-and-access.md)。
