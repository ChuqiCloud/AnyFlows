# API 目录与在线调试

AnyFlows 在公开首页提供 API 目录页面，入口为 `/api`。页面适用于接口查阅、权限确认和小范围请求验证；正式业务调用仍应由应用程序直接请求网关或管理 API，并使用独立的密钥管理方案。

## 访问范围

目录由服务端根据当前请求主体生成。接口不会先把完整 OpenAPI 文档发送到浏览器，再由前端隐藏不可用项目。

| 访问主体 | 可见内容 |
| --- | --- |
| 游客 | 公开接口、统一模型网关接口 |
| 登录用户 | 游客可见内容，以及当前用户可调用的个人和企业会话接口 |
| 平台管理员 | 完整目录，包括管理接口 |

目录中的“可见”只表示可以查看接口元数据和契约；是否能成功执行请求仍由目标接口的认证、权限、额度、模型白名单和其他业务规则决定。

## 目录接口

### `GET /api/explorer/catalog`

返回当前身份可见的接口列表、标签和分页信息。支持以下查询参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `q` | string | 在操作 ID、路径、摘要和描述中进行不区分大小写的匹配 |
| `tag` | string | 按接口标签筛选 |
| `page` | integer | 从 1 开始的页码，最大值为 10000 |
| `page_size` | integer | 每页条数，范围为 1–100，默认 24 |

响应包含 `operations`、`tags`、`total`、`page`、`page_size`、`has_more` 和 `viewer`。目录按标签、路径、方法和操作 ID 稳定排序，客户端可以使用 `has_more` 继续读取后续页。

### `GET /api/explorer/catalog/{operation_id}`

返回一个已通过当前权限投影的操作及其 OpenAPI 操作对象。不存在的操作和当前身份不可见的操作使用相同的无效请求结果，避免通过接口差异枚举目录内容。

## 在线调试

页面会在选中接口后显示路径参数、查询参数、请求体以及响应契约。只有服务端标记为 `debuggable` 的接口显示执行按钮：

- 通过安全白名单的 `GET` 接口可以在线执行；OAuth、SSO、Webhook、初始化和特殊凭据接口即使使用 `GET` 也保持文档-only。
- 统一模型网关的 `POST /v1/...` 接口可以在线执行，包括 OpenAI Chat、Responses、Embeddings、Images、Audio、Anthropic Messages 和 Gemini 入口。
- 管理端写入操作、OAuth 和企业 SSO 启动流程、Webhook、初始化接口以及要求特殊凭据的接口仅提供文档，不提供在线执行。

页面请求从当前站点发出，响应区域显示 HTTP 状态码、耗时、`x-request-id`（如果服务端返回）和截断后的响应正文。页面不会代替客户端处理流式响应或长时间任务，生产调用应使用对应 SDK 或 HTTP 客户端。

## 认证与凭据

目录查询可以由游客发起；登录后页面会附带当前管理会话，以获得用户或管理员对应的目录。会话只用于管理接口，不能作为模型网关凭据。

调试网关接口时，在页面输入用户或企业 API Key。页面将其放在当前请求的 `Authorization: Bearer <api-key>` 头中，不写入 URL、浏览器持久化存储、服务端目录或日志。页面关闭或刷新后需要重新输入。API Key 的签发、轮换和撤销规则见 [认证与访问指南](./authentication-and-access.md)。

示例：使用用户 API Key 调用 OpenAI Chat 兼容入口。

```bash
curl https://<host>/v1/chat/completions \
  -H 'Authorization: Bearer <api-key>' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "<model>",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

请求能否执行还取决于 API Key 的状态、模型白名单、IP/CIDR 白名单、额度、并发限制以及当前渠道可用性。目录页面不会绕过这些约束，也不会显示上游凭据、数据库信息或内部错误诊断。

## 缓存与安全边界

目录和详情响应使用禁止缓存的响应头，以避免不同登录主体之间复用权限投影。服务端在返回目录前完成操作分类和权限过滤；前端收到的列表不应被视为授权凭证。

不要把 API Key、管理会话、OAuth 材料或企业 SSO 一次性票据粘贴到接口参数、请求体示例、截图、工单或日志中。调试失败时优先记录 HTTP 状态码、请求 ID 和可公开的错误正文，并按认证文档检查凭据类型和权限范围。
