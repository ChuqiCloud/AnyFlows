# 客户端档案

客户端档案集中管理上游请求的客户端身份和会话策略。平台管理员可以在控制台侧栏打开「客户端档案」；经典前端和 Next 前端提供相同功能。

## 创建和修改

首次使用可以复制内置的标准请求、Claude Code、Codex 或 OpenCode 档案，填写唯一标识和显示名称，再调整适用协议、凭据类型、身份请求头和会话策略。标识使用小写字母、数字、下划线或连字符，最长 64 个字符。

身份请求头仅允许页面列出的字段，不能配置 API Key、Cookie 或认证请求头。服务地址、认证和正文处理由系统内置实现负责。切换服务会保留已填写的身份字段，请检查是否仍适用。图标标识使用前端已支持的品牌名，例如 `OpenCode`、`OpenAI` 或 `Anthropic`；无法识别时显示通用图标。

点击「校验配置」检查字段是否合法，再创建档案或发布修订。校验不向上游发送推理请求，也不证明模型可用。内置档案不能直接修改，需要先复制。目录支持名称和标识搜索、服务与状态筛选，每页 25 条。

## 给渠道选择修订

在渠道列表点击指纹图标，打开「客户端档案配置」。选择兼容档案，再从修订历史选择要使用的版本，确认后点击「切换到此修订」。渠道配置与档案编辑分别保存。

渠道绑定固定的标识与修订。发布新修订不会自动更新渠道；需要回滚时重新选择兼容的旧修订。服务端还会检查凭据及同名请求头冲突，页面列出兼容项不替代最终校验。旧版 Claude 身份配置与新档案冲突时，先关闭旧版配置并保存渠道，再切换档案。

在档案详情中可以查看修订历史和渠道引用。停用档案会使绑定渠道在运行时配置更新后拒绝新请求，已经开始的请求继续使用原快照；多节点之间存在配置传播时间。

## 会话策略

默认使用调用方明确提供的会话标识。自定义档案也可以选择「明确标识优先，首条消息尽力关联」：没有明确标识时，根据首条用户消息生成隔离后的摘要。相同主体使用相同开场仍可能关联到同一会话，客户端应优先提供稳定会话标识。

会话关联不授予跨账号读取上游响应状态的能力。无法安全表达的私有响应续接参数仍可能被拒绝。

## OpenCode 渠道

创建渠道时选择 OpenCode，并按模型原生协议选择 Chat、Responses 或 Messages。服务地址由系统内置，不需要填写 Base URL。

在凭据抽屉选择 API Key 或「公开访问」。公开访问不填写密钥，渠道只允许一条公开凭据，不能与 API Key 混用；如需两种方式，请分别创建渠道。公开凭据参与并发、健康及调用统计。选择客户端档案时使用兼容的「OpenCode（公开访问）」或自定义档案；现有 OpenCode 档案的冻结修订继续仅适用于 API Key。

公开访问由上游决定实际可调用模型，不保证免费模型始终可用。目录返回成功不代表推理成功；模型名称包含 `free` 也不会自动发布为免费。公开渠道调用失败直接返回，不会自动切换到其他渠道或收费 Key。

渠道的「客户端档案配置」提供 Inference v1 和 Zen v1 入口切换。入口单独保存，不会重写凭据或渠道其他设置；切换后应重新发现模型并确认实际调用。

需要完整客户端工具形状的模型，可以在「客户端档案配置」中开启「完整工具兼容」，默认关闭。系统补充内置工具声明；已有同名工具保留原来的参数和语义。网关不执行命令或读取文件。

如果模型只调用了不可用的内置工具，且尚未返回有效内容，系统最多说明一次工具不可用并请求续答。已经返回内容、混合调用真实工具或再次调用不可用工具时，本次请求失败。两轮共用凭据、会话、输出上限和总超时，按一次请求结算。

上游使用 SSE 时，下游仍可选择流式或完整 JSON。Chat、Responses 和 Gemini 保留可表达的推理文本。转为 Messages 时，服务端会协商不输出无签名思考，推理用量仍计入统计；明确要求无法转换的思考输出时会拒绝请求。

配置校验通过不等于推理可用。保存后请使用渠道探测和实际 API 调用确认，档案页暂不提供独立的真实推理探测。

## 检查上游请求头

管理员在「调试追踪」中开启请求头采集后，发起一次模型调用。打开对应记录，点击「查看 Header」，展开「上游请求记录」下的候选，再查看「请求头」。这里保存的是客户端档案和服务适配器处理后的上游请求；「下游请求」保存调用方传入的原始请求，两者不同。

OpenCode 请求可检查 `x-opencode-client`；启用会话关联时，还会生成 `x-opencode-session`、`x-opencode-session-id` 和 `x-opencode-project` 等服务字段。档案中的 `User-Agent` 会实际发送，但日志中的值固定脱敏，认证字段也不会显示明文。修改采集设置只影响后续请求，未采集的历史记录无法补回。

请求头正确不代表上游允许调用。OpenCode 免费模型可能因服务器出口 IP 被限制；遇到这类错误，应同时检查上游响应状态和错误正文，不能仅根据目录查询成功或客户端身份字段判断可用性。
