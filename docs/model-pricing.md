# 模型价格

模型支持以下计费模式。

| 模式 | 价格单位 | 说明 |
| --- | --- | --- |
| 按 Token | 美元 / 百万 Token | 分别设置输入、输出和缓存价格，按实际用量结算。 |
| 按次 | 美元 / 请求 | 设置大于零的基准价，每个成功请求结算一次。 |
| 免费 | 无 | 仍记录用量，不扣除额度。 |
| 表达式 | 由规则计算 | 根据实际用量和表达式结算。 |

按次价格独立于五类 Token 价格保存。平台请求按分组、模型和时段倍率调整价格，再将美元金额换算为额度。商户请求使用商户销售倍率。命中企业合同价的请求使用合同约定的 Token 价格。

管理员可在模型价格工作台查看 models.dev 和 LiteLLM 公开价。models.dev 会读取完整提供商目录，并以来源中的模型 ID 匹配本地 Canonical 模型 ID，不要求提供商名称一致。多个提供商提供同一模型 ID 时，优先选择非零输入价较低的记录，来源 ID 用于稳定排序。LiteLLM 仍按模型 ID 与提供商精确匹配。

在模型价格页点击「获取参考价」，页面会列出匹配到的本地模型。逐个打开模型，核对来源厂商和参考价，选取需要替换的字段并加入待提交列表。确认应用后才更新正式价格。参考价用于按 Token 定价，分层价格、弃用标记和缺失字段会提示复核。

具有独立价卡的异步视频接口继续按时长和分辨率计价。

## 导入 LobeHub 目录

在「模型管理 → 模型目录」点击「导入 LobeHub 目录」，可批量导入随版本提供的厂商和模型快照。同一个 Canonical 模型 ID 只创建一条记录，快照保留该 ID 对应的全部来源厂商。已有厂商配置和模型记录会跳过。新模型以隐藏草稿保存，核实能力、配置价格和绑定渠道后即可按现有流程发布。

导入过程中可以停止。再次执行会核对已保存的条目，从剩余条目继续。快照包含模型名称、类型、上下文窗口和可用的能力资料，报价继续通过模型价格工作台维护。

数据来自 [LobeHub model-bank](https://github.com/lobehub/lobehub/tree/5779bbdd3d0f04bba82f88e2581f41d19e1eda52/packages/model-bank)。维护者可运行 `node web-next/scripts/export-lobehub-catalog.mjs <LobeHub 源码目录> <commit SHA>` 更新快照。图标由项目锁定的 LobeHub Icons 版本提供，更新依赖后运行 `node web-next/scripts/export-lobehub-icons.mjs` 重新生成索引。
